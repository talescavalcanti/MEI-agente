# acervo

Componentes copiados de `projetos/componentes/web/src/library` (o acervo da equipe), com o
código original. Só a identidade muda: as cores e fontes vêm dos tokens `--c-*`, que a
landing (`../lp.css`) redefine dentro de `.lp`.

| Pasta | Onde aparece na landing |
|---|---|
| `process-rail` | "Como funciona": as cinco etapas de uma mensagem. Acréscimo: prop `head`, para o título ficar no palco sticky. |
| `roller-number` | Números do Sebrae na seção do problema. |
| `reveal-accordion` | Perguntas frequentes. |
| `watermark-rise` | A marca gigante no rodapé. |
| `kit` | Núcleo compartilhado (GSAP, Lenis, helpers). |
